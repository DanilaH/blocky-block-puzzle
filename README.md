Приоритет: явное актуальное решение владельца → DECISIONS → исходное ТЗ. ROADMAP определяет последовательность и проверку, не сокращает обязательный релизный scope. Исследование — обоснование и ограничения доказательств, а не контракт реализации.

Стек: TypeScript + Phaser + Vite + Capacitor; нативный Yandex Mobile Ads; HTML/CSS для меню, без отдельного React-слоя. Версии закреплены в package-lock.json.

Первый релиз: Classic, подсказки, комбо, выразительный звук/эффекты, обе ориентации, сохранение, три рекламных формата, аналитика. Кампания — отдельный этап в этом же приложении по D30: пилот реализован по D31; аппаратная и человеческая приёмка открыты.

Исходные документы перенесены из предоставленных файлов от 23.10.2026; §12 ТЗ уточнён 02.11.2026 по решению D30. У имени файла исследования снят суффикс « (1)», чтобы сохранить исходные относительные ссылки.
