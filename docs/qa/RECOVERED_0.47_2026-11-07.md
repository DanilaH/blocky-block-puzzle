Незавершённый чат не уничтожил исходники. Наличие удалённого коммита проверяется отдельно; прежняя фраза о завершённом сохранении в GitHub опережала результат.

## Объединение

Метаданные используют APP_VERSION=0.47.0-preview, совпадающий с Android versionName; versionCode=47. Новые постановки очисток, звук, нативные haptic-последовательности и запрет похвалы при поражении сохранены. `src/core` идентичен исходной восстановленной 0.47; новых политик выдачи нет.

## Сохранность и точка продолжения

Объединённый код и текстовые отчёты сохранены в удалённой ветке `feat/classic-preview`, коммит `561e8c7`; вторым родителем сохранена история PR #2. Удалённая ревизия скачана обратно: различий с проверенным рабочим деревом в `src`, `android`, `public`, `tests`, `e2e`, `scripts`, workflow и зависимостях нет. Ядро `src/core` также совпадает с восстановленной `c79025e`. Для отправки использован один пакет содержимого без Base64 и отдельных create_blob-загрузок. Новые тяжёлые исследовательские бинарные файлы в этот пакет не переносились; они остаются в локальной истории.

Готовый APK 0.47 передан для плейтеста. Следующая содержательная приёмка требует физического телефона: установка обновления, запись 2–3 обычных партий, перенос/эффекты/звук/вибрация, реальные рекламные возвраты и экспорт журнала. Просадка при полной очистке со сменой темы остаётся открытой: ни один исследованный вариант не доказал ускорения, разрешение и качество не снижались. Новых оснований менять flow-v4 нет.
