# Изоляция сбойного расчёта хода — 07.11.2026

База: `df5f330`, ветка `feat/classic-preview`, preview 0.46. Это отдельное исправление над доступной GitHub-версией, не новая 0.47. Локальные изменения другого окружения от 7 ноября сюда не перенесены; при объединении сохранить их.

## Подтверждённая ошибка

После таймаута 5 секунд `calculateMove` оставлял worker живым. Повторный ход назначал ему новый `onmessage`. Поздний ответ предыдущего задания мог разрешить Promise нового хода. Проверка текущего gameId/revision не различает два разных хода из одного состояния.

Исходная функция из `src/main.ts` воспроизведена с управляемыми часами/ответами: первый запрос завершился `Move search timed out`, второй принял результат первого запроса. Это воспроизведение гонки обработчиков, не наблюдённая частота на телефоне.

## Исправление

Расчёт вынесен в `MoveCalculator`. При таймауте, ошибке worker, ошибке десериализации ответа, ошибке отправки или сообщённом отказе поиска он очищает таймер/обработчики и завершает worker. Следующий запрос создаёт новый экземпляр. Отложенный callback завершённого запроса игнорируется. Исправный worker переиспользуется; параллельный запрос отклоняется без замены текущего обработчика. Первый экземпляр создаётся при первом расчёте новой тройки.

Существующий порядок «расчёт → атомарная запись → публикация» сохранён. Алгоритм flow-v4, RNG, очки, форматы сохранений и версия APK не меняются. По-прежнему 5 секунд до ошибки; переход на синхронный тяжёлый поиск не добавлен.
