## Короткий плейтест

1. Установить APK поверх 0.73, игру не удалять.
2. Пауза → «Новая партия» → «Другие варианты выдачи» → **«Все базовые фигуры · проба»** → «Новая партия».
3. Сыграть 1–2 партии. Каждую пробу выбирать явно: обычная новая партия и повтор после поражения запускают основной v2. Старая сохранённая партия продолжает прежнюю policy.
4. Оценить разнообразие, интересность решений и темп относительно 0.73; не вернулись ли бесконечные очистки и нет ли чрезмерной жёсткости. Все десять ориентаций за одну партию не гарантированы.
5. Запись желательна: пауза → «Ещё настройки» → «Запись партии для разбора» → «Начать запись». До закрытия приложения выгрузить JSON через «Выгрузить запись партии». Только ощущения тоже полезны.

Остаются физические Android update/resume, плавность/нагрев/память и оценка владельца. Live ads/ILRD/кабинет/доход не проверялись, AppMetrica отложена владельцем: demo ads / analytics OFF. **KIT IMPACT NONE**: consumer-specific каталог и политика Blocky; guidance `4e826ff378dfd2f4705a31a894400ae6268ca6f9`, runtime `5450f9db344aacb5acdc103b4199fd8aeb11b10d`. mini-games-kit не изменялся.
