## Найденный polling геометрии
Первый полный CI 41293485113: 92 unit прошли, browser 98/99. Упал строгий тест drag: одно чтение board.getBoundingClientRect между pointermove и кадром. Диагностический локальный прогон с окном 650 мс воспроизвёл 3 чтения; все стеки ведут в Phaser ScaleManager.getParentBounds → step, не в обработчик pointermove.

У fixed-size canvas с DOM-вводом отключён периодический polling (`resizeInterval: Infinity`), реальные изменения размеров инвалидируются через ResizeObserver; window resize/orientation по-прежнему обрабатываются движком и отменяют жест в приложении. Ввод открывается после первого postrender. Ужесточённый тест теперь держит окно 650 мс и по-прежнему требует ровно ноль чтений. После исправления 13 browser checks (drag, safe-area, multi-touch, материалы, поворот/сон/восстановление WebGL) прошли.

Скриншот хрома из работающего приложения: [chrome.png](materials-0.28/chrome.png).

Финальное исправление polling: усиленный drag-test прошёл ещё 5 повторов. Повторные software-профили (`performance-final1/2.json`) сохраняют медиану 16,7 мс; p95 комбо 50,0 / 33,4 мс против 33,4 / 33,4 мс в двух baseline. ScriptDuration комбо 101,5 / 99,8 мс против 105,8 / 122,2 мс. Idle-drag: чтения геометрии за весь измеряемый сценарий 7→1, нулевой LayoutCount сохранён; единственное чтение — тестовый boundingBox перед жестом. Полный комбо-сценарий 12–13→6 чтений; оставшиеся нужны отдельным эффектам/событиям, не pointermove. Max long task остаётся 108–109 мс против 65–68 мс baseline: суммарную победу по FPS/спайкам не заявляем. Профили ограничены software Chromium; проверка GPU Android остаётся открыта.

Повторный CI 41294480588: 92 unit, 95/99 browser; исправленный drag прошёл. Четыре reload-проверки festival/preflight зависали на aria-busy, поскольку искусственные часы оставались остановлены после перезагрузки и блокировали обязательный первый RAF. Проверки сохранённого счёта, рекорда, вибрации и bounded effects не удалены и не ослаблены. Четыре проблемных сценария после исправления прошли локально.
