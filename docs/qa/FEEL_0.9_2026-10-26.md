## Баланс: 4 000 партий

Повторены обе политики на seed 1…1000 для каждого из двух игроков. Случайный игрок использует отдельный LCG и выбирает из всех допустимых ходов. Поисковый игрок — детерминированный beam search ширины 3, глубиной до оставшейся тройки. На каждом уровне перечисляет допустимые продолжения и оставляет три лучших; ранг: длина последовательности, очищенные линии, число пустых клеток, меньше изолированных пустот, больше соседних пустых клеток. При равенстве сохраняется порядок перечисления. Будущую выдачу бот не смотрит, кредитами подсказок не пользуется.

Это отдельный ограниченный поисковый игрок, **не** штатная подсказка и не оптимальный игрок. Его узкий beam и эвристика могут влиять на выводы. Нельзя приписывать его результат человеку или качеству подсказки.

Лимит — 150 ходов на партию. Достигшие его незавершённые партии отмечены `over:false`. Перцентили сырых ограниченных значений в JSON не являются оценкой настоящей длительности, когда распределение упирается в лимит.

| Игрок / выдача | Медиана длительности | Дошли до лимита незавершёнными | Без очисток | Поражение после первого хода тройки |
|---|---:|---:|---:|---:|
| Случайный / initial-v1 | 14 | 0 / 1000 | 371 | 219 |
| Случайный / solvable-v1 | 14 | 0 / 1000 | 311 | 156 |
| Поисковый / initial-v1 | ≥150, не определена | 746 / 1000 | 0 | 31 |
| Поисковый / solvable-v1 | ≥150, не определена | 905 / 1000 | 0 | 0 |

Fallback выдачи — 0 во всех группах. Среднее число очищенных линий **за наблюдаемый отрезок**: 1,552 / 2,116 у случайного игрока; 59,439 / 64,422 у поискового (initial / solvable). Средний максимум серии за этот отрезок: 0,765 / 0,888 и 3,589 / 3,707 соответственно. Состав выданных фигур по размеру и семейству, score, линии, серии, число узлов и состояние конца сохранены для каждой партии.

Вывод: solvable-v1 помогает этому поисковому игроку доживать до заданного горизонта и уменьшает число неудачных партий случайного игрока. Это основание для человеческого сравнения, а не автоматического выбора релизной политики. Для сравнения длинного хвоста поисковых партий потребуется увеличить лимит; текущая выборка этого вопроса не решает. В приложении остаётся initial-v1.

Данные: [сводка](feel-0.9/balance-summary.json), [initial-v1 JSONL.gz](feel-0.9/balance-initial-v1.jsonl.gz), [solvable-v1 JSONL.gz](feel-0.9/balance-solvable-v1.jsonl.gz). Сжатие только для хранения; внутри одна JSON-запись на партию. Воспроизведение из корня репозитория:

```sh
node scripts/balance.mjs initial-v1 1000 150
node scripts/balance.mjs solvable-v1 1000 150
```

Скрипт создаёт несжатые JSONL. Чтобы расширить горизонт, заменить последний аргумент. M2 целиком не закрыт: нужны человеческие попытки и аппаратное профилирование подсказки.

## Что проверить на телефоне

Записать модель, Android и WebView. Эти пункты не отмечены пройденными:

1. Установить обновление поверх 0.8 без удаления; проверить сохранённую партию, рекорд и настройки.
2. В портрете и альбоме проверить зазор над нижней зоной, края поля, фигуры и обучение. Повторить с доступными на устройстве жестовой навигацией/системными кнопками.
3. Перенести фигуру к нижней строке и углам, добавить второй палец, отпустить в обоих порядках. Ход не должен состояться. Следующий одиночный жест должен работать.
4. Быстро сделать несколько установок и очисток: фигура следует за пальцем, звук установки слышен, награды не мешают следующему ходу.
5. Свернуть во время переноса и очистки, вернуться, повернуть экран, проверить Back. Незавершённый жест отменён; принятый ход сохранён один раз.
6. Поиграть 15–30 минут: отметить задержки, нагрев, утомляющий звук. Для утверждений о производительности нужны измерения на слабом и обычном Android, а не только субъективный отзыв.

Человеческий баланс проверять отдельно: 5 человек × 3 попытки на каждую политику, чередуя порядок. Для этого потребуются тестовые сборки с заданной политикой; текущий APK не содержит скрытого пользовательского переключателя. Фиксировать первую очистку, причину поражения со слов игрока, понятность серии и желание повторить. Время человека не выводить из количества ходов бота.
