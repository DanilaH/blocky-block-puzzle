## Проверки

[PR1 CI 43835669338](https://github.com/DanilaH/blocky-block-puzzle/actions/runs/43835669338) завершился успешно во всех jobs: 352 unit, build/assets, анализаторы и public-data guard; 266 browser-сценариев за 21.5 минуты; 36 focused browser; Android unit/build/proof и 2 emulator tests — PASS. Старый showcase прошёл без изменения теста, обе проверки delayed-write также прошли в полном наборе.

Локально прошли 28 затронутых browser-сценариев, включая неизменённый старый showcase, обе искусственные задержки записи и реальный worker/export нового режима. Ранее прошли 1120 точных/независимых переходов из старых человеческих записей. Эмулятор проверяет запуск и существующие сценарии, не физическую плавность или человеческую сложность нового режима.

Полный CI 0.68 дал 263/264 browser PASS; его ошибка не скрывалась ретраем или увеличением timeout. До исправления оба новых delayed-write теста теряли Back. После исправления они проверяют решение до истечения таймера и ровно по одному событию отказа/завершения. Код выдачи, её замороженные критерии и holdout не перенастраивались.

## Публикация

Первую попытку публикации 0.68 остановил auto-review, расценив QA JSON как производные частных записей. Для следующей поставки содержание сокращено: публично только агрегаты и синтетические seed/hash recipes. Полные синтетические снимки сохранены отдельно и в ignored artifacts. Чистый публичный a6e0af8 имеет одного parent dc26d27, а 0.69 идёт от него. Локальные промежуточные checkpoint со снимками в публичную ancestry не включены. Исходные 402+261+185+272 хода владельца остались в private-inputs и не добавлялись в Git. Guard проверяет единственный публичный QA JSON и отсутствие полей board/tray/move/events/witness/gameId/trace. Mini-games-kit не менялся.

Обычный Git push чистой ветки завершился ошибкой credentials: `could not read Username for https://github.com; terminal prompts disabled`. После проверки использован ранее разрешённый путь цельного UTF-8 tree: полные файлы одним деревом, сверка SHA с локальным tree, без blob API, base64 и разрезания файлов. Публикация и Actions разрешены владельцем; записи, ключи и APK в Git не публиковались.
