# Проверка воздействий, 07.11.2026

Протокол фиксируется до первого запуска. Только офлайн; production flow-v4 не меняется.

Свежие seed: 71001–71004 development, 81001–81004 confirmation. Генерирующие стратегии clear/space/three/plausible. Снимки только на полной новой тройке при первом достижении 12, 30, 60 ходов. История последних четырёх реально выданных троек. Одинаковые состояния для всех воздействий. Это связанные снимки синтетических партий, не независимые люди. Confirmation — новые seed, а не доказательство человеческого UX.

Общий пул: базовая тройка + 3 новых flow-v4 + 4 независимых взвешенных тройки. Отбор: явное доказательство размещения всех фигур; не найденное доказательство не означает невозможность. Прогноз — существующая bounded resilience, две модели lines/space. Независимая оценка — шесть существующих стратегий, без доступа к прогнозам/свидетелям. Никакого обучения между позициями. Базовая выдача сохраняется при отсутствии допустимого улучшения.

Воздействия: diversity минимизирует совпадение фигур с историей; recovery уменьшает прогноз конечной занятости; reward повышает прогноз линий; challenge снижает модельную устойчивость в ограниченном диапазоне, сохраняя доказанный путь. Это проверка прокси, не определение эмоций.

Предварительные инженерные gates (по каждому split отдельно): не менее 20% замен; снижение успеха розыгрыша не более 2 процентных пунктов для diversity/recovery/reward, не более 10 п.п. для challenge; никаких замен без replay-свидетеля. Diversity: среднее совпадение с историей ниже хотя бы на 20%, линии >=90% базы. Recovery: минимум на 2 клетки ниже занятость среди пар, где обе выдачи успешно разыграны; линии >=90%. Reward: минимум +10% линий без снижения числа all-clear. Challenge: снижение успешности независимых ботов на 2–10 п.п. (только техническая чувствительность, не цель смертности людей), линии >=90%. Гейты проверяются также по каждой стратегии; эффекты на отдельных сценариях показываются отдельно. Unknown и fallback выводятся явно. Если на confirmation хотя бы один gate не выполнен — воздействие не принято.

Время — облачный Node, не FPS/Android. Учитываем весь построенный пул. Горизонт — одна тройка; выводов о длительности партии и динамике повторов за сессию нет. Дальнейшая проверка сериями потребуется даже для прошедшего воздействия. Пороговые числа — заранее выбранный скрининг, не научные нормы.
