# D81 — длинный путь существует, но выдача его фигур остаётся хрупкой

**Решение: сохранить диагностику; новый runtime-кандидат не принимать.
APK0.63/director-v2 сохранена, C1/D79 остаётся REJECT.**

На29 из31 позднего инженерного поля D80 найдены пути к all-clear за5–9 ходов
с обычными очистками. Но фигуры этих путей не дают устойчивой награды прежнему
неточному боту. Перепланирование по фактическому полю помогает отдельным
продолжениям; общий результат не проходит рубеж доступности.

## Проба и существование путей

Это прежние31 связанных состояния четырёх C1/bounded партий, не свежая выборка,
не полные партии и не люди. Офлайн beam96/horizon9 оценивает только геометрию:
`-200*минимальный row/column cover -4*клетки +сумма квадратов наполнений линий`.
Есть полный обратный индекс последнего хода; промах beam остаётся unknown.
Разведочный запуск дал29/31, после него до продолжений зафиксирован
[протокол](geometry-recovery/protocol.md). Коэффициенты не менялись.

| Свойство | Результат |
|---|---:|
| Найден путь за≤9 размещений |29/31|
| Путь не найден |2, unknown|
| Длины найденных путей |5:3 поля;6:2;7:8;8:9;9:7|
| Очищенных линий |176|
| Обычных ходов с очисткой до финальной награды |128|
| Максимум ходов без линии, включая начало/конец |2|

Длина найденного пути не является точным минимальным расстоянием. D80
по-прежнему точно исключает награду за≤3 на всех31 полях. Два новых промаха
не доказывают невозможность за9. Фазы или сохранённая будущая цель не вводились.

## Проверка после разумных локальных ходов

Пять замороженных квантилей неизменённого boundedOptions:0,.25,.5,.75,.999999.
Бот видит поле/текущую тройку, не witness. Парные условия имеют одинаковую
первую тройку и первые действия. Fixed продолжает первоначальную последовательность;
Rebuild после каждой полной тройки ищет продолжение по фактическому полю с
остатком6/3 хода. Между действиями тройка не меняется. Фактический лимит9 ходов.

| Исход |Fixed|Rebuild|
|---|---:|---:|
| Коррелированных эпизодов |145|145|
| Награда получена |5|11|
| Полей с наградой хотя бы в одном варианте |4/29|8/29|
| Полей с наградой во всех пяти вариантах |0/29|0/29|
| Тупик оставшихся фигур |11|7|
| Поиск не нашёл продолжение за6 (unknown) |—|93|
| Точно нет награды в оставшиеся≤3 |—|26|
| Лимит ходов без награды |129|8|

Парно:5 общих наград,6 только Rebuild,0 только Fixed,134 без награды в обоих.
Два исходных unknown остаются в покрытии31; продолжения для них не запускались.
Пять вариантов не являются независимыми партиями или вероятностью успеха людей.
На7 полях все квантили дают один первый ход; на11 — пять разных. Остальные:
8 полей с двумя,2 с тремя,1 с четырьмя первыми действиями.

Последний неполный лоток дополнен одиночными клетками после доказанной награды;
Fixed дополнен до9 ходов.43 таких клетки на29 witness явно отмечены в данных.
Перестановка слотов[2,0,1] не раскрывает хронологический порядок пути.

Нельзя сравнивать503 линии Fixed с354 Rebuild общей суммой: Rebuild часто
останавливается на unknown,605 фактических ходов против1226. На общей первой
тройке у обоих237 линий за одинаковые действия. К третьей дошли130 против15.

## Где теряется преимущество

У27/29 witness хотя бы одно действие вне boundedOptions; у14 уже первое.
13 путей в некоторый момент требуют пропустить доступную немедленную линию.
Только2 полностью лежат в разумном наборе бота — это не гарантирует их выбора.
Средний cover исходных29 полей5.97, после трёх точных размещений3.48.
После трёх bounded-ходов5.73 на139 завершивших первую тройку продолжениях;
шесть ранних тупиков в среднее не входят. Улучшение выбранного witness не
переносится автоматически на альтернативные действия.

Пример: seed2441001, исходный ход12. Witness начинает O2 в(6,0), ноль линий,
75-е место локальной оценки, разрыв240, вне top5. Бот с квантилем0 ставит
I5 в(0,0) и сразу очищает линию. Со старым будущим набором награды за9 ходов
нет. Перестроение после тройки приводит к другой награде на8-м ходе.
Это воспроизводимый отдельный успех, но ни одно поле не выдержало все пять
вариантов. boundedOptions не равен человеку; его оценка не доказывает, что
человек не увидит путь. Будущие тройки игроку тоже не известны.

Наглядный разбор всех полей: [replay.html](geometry-recovery/replay.html),
автономный просмотрщик без внешних ресурсов. Есть выбор поля, квантиля, шага,
точный маршрут, Fixed/Rebuild и фигура/линии перед очисткой.

## Следующий рубеж

Не превращать witness→три фигуры в очередной принятый генератор. Следующую
подготовительную тройку нужно оценивать по состояниям после видимых разумных
действий игрока; продолжение строить по фактическому полю. Наличие продолжения,
обычные линии и цена отклонения проверяются до runtime. Положительный путь и
малый cover — материал, а не критерий доступности. Дополнительные фазы/веса
этим результатом не обоснованы.

D80 закрыт только в части существования длинных путей на29 полях. Устойчивое
ветвление, бюджет и полноценный кандидат открыты. Human A/B flow-v4/v2, POCO
и полный объём партий остаются отдельными gates.

## Воспроизведение

```sh
node scripts/director/geometry-recovery.mjs
python3 scripts/director/verify-geometry-recovery.py
node scripts/director/verify-geometry-recovery.mjs
python3 scripts/director/render-geometry-recovery.py
npx vitest run --maxWorkers=4
npm run build
```

Нужны Node, зависимости, Python3 и g++17. Сбор перезапишет D81 results;
D79/D80 не меняются. Никаких Git blob API, base64 и переноса кусками.
