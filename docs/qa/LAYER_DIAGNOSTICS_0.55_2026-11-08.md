# Preview0.55 — один автоматический разбор слоёв

## Реализация и границы

Основа — обычная 0.54. Phaser4.2.1, старый RAF, Canvas2D внешних эффектов, подложка поля и разрешение сохранены. Экспериментальные GPU/composited/clock варианты из draft PR3 сюда не переносятся. Эта сборка диагностическая: устранение рывка не объявляется.

Пауза → Ещё настройки → Диагностика → **Проверить слои · около 90 секунд**. Один Start, один ZIP `blocky-layer-result.zip`. Старый 15-секундный сценарий остаётся доступен отдельно. Оба перехода защищают невыгруженную добровольную запись игрока.

Все игровые операции проходят настоящие ClassicUI, worker, атомарное IndexedDB-сохранение и награды. Тест использует отдельную `blocky-clear-trace`, не пишет обычную базу и её backup; реклама и native product analytics отключены. Fixture тот же: две колонки,121→1574, wardrobe1→5, reveal2. Логические итоги обязаны совпадать при всех отключениях; no-theme удерживает только видимое оформление 1.

## Протокол

18 эпизодов: один warmup, два прохода по 8, один финальный native-baseline. В каждом проходе baseline → шесть отключений → baseline; во втором отключения в обратном порядке. До каждого хода 1.8 сек settling, после хода 2.4 сек. Примерная длительность 76 сек плюс перезаписи/экспорт native-трассы; UI указывает 90 сек. Время и полная последовательность записываются в JSON. Предельная длительность 120 сек, ручное прерывание, Back/фон/resize/context loss безопасно останавливают прогон.

Основные 16 сравнений **без Android tracing**. Трасса начинается только после них и относится к отдельному последнему baseline; она не участвует в FPS-сравнениях. Watchdog25 сек/64MiB вывода сохранены. При отсутствии/переполнении трассы JSON всё равно доступен с явным статусом; пропуски internal buffer не считаются отсутствием GPU-работы.

| Условие | Что отключено | Что сохраняется |
|---|---|---|
| no-board-ink | Submission примитивов SpriteInk | Таймлайн события, общие координатные расчёты, плитки, VFX |
| no-board-vfx | Создание/обновление VfxSprites stamp | Примитивы, плитки, внешние частицы |
| no-festival | Весь burst/draw внешнего Canvas/SVG праздника | Смена темы, поле, атмосферный фон |
| no-atmosphere | Только анимированный ambient Canvas | DOM-фон и его смена цвета |
| no-reward-dom | Создание надписей/эмблем/перелёта очков и связанных вспышек | Логические награды, тот же момент поступления очков, набор HUD |
| no-theme | Presentation palettes удерживаются на 1 | Wardrobe/награда действительно переходят на 5; число/траектории частиц сохраняются |

Локальный cosmetic seed Festival сбрасывается на 0x5120cafe, фаза/веса Atmosphere — перед каждым эпизодом. Игровой PRNG и исходная сохранённая партия не меняются. Это контролируемое сравнение одного хода, не полный replay исходной человеческой сессии. Общая геометрическая математика остаётся даже при no-ink/no-vfx; отрицательный результат не исключает её CPU-стоимость.

В каждом эпизоде записаны счёт/поле/wardrobe/видимая тема, созданный rewardDOM, число реально выполненных draw, peak primitive/stamp counts, Festival burst/spawn counts, размеры canvas. `validateLayer` проверяет и отсутствие выбранного слоя, и наличие остальных. Если условия не подтвердились, результат не номинируется. Fast-режим доступен толькоDEV и всегда marked functionalOnly: из него нельзя получить performance-кандидата.

Summary сравнивает каждый вариант с baseline до/после того же прохода. Цель: ≥50% меньше интервалов>33.4 мс в обоих порядках, максимум не хуже baseline в пределах 1 мс; control drift≤max(2 интервала,50% среднего контроля). Слишком мало кадров, нулевой исходный лаг, неполный/невалидный проход не дают победителя. Это только номинация следующего исследования, не доказательство готового ускорения и не GPU execution time.

## Защита native-экспорта

`reset` очищает ready и старый trace перед новым прогоном, включая отмену до записи. Каждый native start получает captureId; JS принимает готовую трассу только от начатого в текущем запуске capture. `share` получает явный includeTrace: отменённая до start проверка или несовпавший capture не прикладывают старый файл. Native архив выбирается только из двух фиксированных имён, а не произвольного пути. Все операции по-прежнему добровольные, локальные, debug/API28+ для tracing.

## Проверки

Локально 225unit/build и 12 browser-сценариев старой/новой проверки и provenance прошли, включая полный 18-эпизодный прогон (около 80 сек), все valid flags,148 созданных внешних частиц в условиях с Festival, финальный 1574, сохранение обычного профиля и один неизменный backing. Последующее уточнение summary добавляет ограничение drift; UI сделан прокручиваемым на коротком экране. Финальные UI/CI/Android/APK проверки записываются после завершения. Физическое выполнение 0.55 на POCO пока открыто.
