# Preview 0.56 — подготовленные надписи наград и переходы Classic

## Причина и реализация

Физический прогон 0.55 номинировал reward DOM и смену оформления. Эта версия убирает анимацию неиспользуемого `--enamel-local` в плоских поверхностях Classic, сохраняя видимый переход `color`.

`RewardLabels` готовит изображения текста и теней из фактических computed styles. Важные надписи используют кеш символов и прежние отрицательные задержки / 650 мс alternate ease-in-out танца; остальные надписи и суммы готовятся целиком. В группе остаются прежние движение/масштаб/opacity, эмблема и перелёт очков. Статические тени и filter готовятся при появлении; в кадровом цикле нет измерения layout или чтения computed styles. Готовые Canvas символов движутся прежними CSS transform-анимациями через браузерный композитор. У нового renderer нет своего rAF, повторного рисования и загрузки пикселей каждый кадр; статические надписи и суммы — один готовый Canvas. Существующий visualClock не меняется.

Computed styles отдельных букв учитываются отдельно от filter родителя. Геометрия DOM резервируется прежнего размера, исходный регистр текстовой метки сохранён в sr-only узле. HUD notices с role=status не меняются. При ошибке Canvas2D / неподдерживаемой тени / исчерпании бюджета остаётся прежняя DOM-отрисовка.

Кеш символов LRU ограничен 12 MiB. Оценка RGBA-хранилища кеша и активных Canvas вместе ограничена 28 MiB (это не полная память процесса/драйвера); старые активные ссылки не уничтожаются при вытеснении. Очистка награды освобождает активный Canvas, ссылки и анимации; повторный finish безопасен. Частая надпись «Чистое поле!» подготавливается во время idle с тем же контейнером и размерами, без работы во время drag/commit/активной награды. На новом viewport используются новые ключи кеша с прежним общим лимитом.

Расчёт и атомарное сохранение не меняются. Константы перелёта/поступления очков 700/580 мс и gameId-защита сохранены. Физический выигрыш 0.56 на POCO ещё не подтверждён.

## Проверки перед выдачей

- 226 unit-тестов и production build прошли локально.
- Действующие сценарии сохранения наград, перекрытия, перелёта, pause/background и новой партии пройдены при разработке.
- Четыре новых browser-сценария: семантика/движение/освобождение; Canvas fallback; полный реальный clear; вытеснение при 36 размерах шрифта. Прошли.
- Игра/пауза/обучение/результат, две ориентации, пять промежуточных цветовых фаз: 40 точных совпадений видимых цветов, поверхностей и геометрии. [Данные](rewards-056/visible-color-parity.json), [проверка](../../scripts/qa-classic-surfaces-056.mjs).
- Новые и прежние надписи просмотрены на четырёх одинаковых фазах: размеры/положение совпали. Это сохранение подачи, не побайтовое совпадение сглаживания растрового и DOM-текста. [Данные геометрии](rewards-056/glyph-geometry.json), [проверка](../../scripts/qa-reward-rasters-056.mjs).

## Сравнение стоимости

Восемь независимых страниц: прежний путь, только Classic, только растр, оба изменения, затем обратный порядок. По три реальных clear-эпизода; вся запись CDP включена, два повтора после warmup участвуют в сводке. Старый путь восстанавливается только инструментом: `prepare` обходит новый renderer, а CSS возвращает прежний transition без вмешательства в правила pause.

Отклонён первый прототип с перерисовкой одной надписи по rAF: style cost уменьшился, но полный renderer main CPU вырос примерно с 750–790 до 1070–1135 мс за 2.4 сек. Назначение этой проверки — не принять уменьшение одного счётчика за ускорение. Итоговый вариант готовит пиксели один раз и использует native CSS animation.

Оцениваются полные style/paint/rAF и renderer tasks, а не только forced layout. Вложенные категории не складываются. Финальный протокол: [browser-comparison.json](rewards-056/browser-comparison.json), [скрипт](../../scripts/probe-reward-056.mjs). Это Linux Chromium/SwiftShader; проценты CPU этого прогона не являются FPS Mali.

## CI и APK

Ожидают окончательного CI, проверки подписи и побайтового сравнения APK. Выдача предполагается обновлением поверх 0.55 с прежним package и сертификатом. После установки — прежняя автоматическая проверка слоёв и один ZIP результата для сравнения с физической 0.55.


В проверке 0.56 теперь 20 эпизодов (около 84 сек плюс сохранение/flush), schema `blocky-phone-layers-v2`: к прежним шести отключениям добавлен `legacy-reward-text`. Он сохраняет новые поверхности Classic и все награды, но обходит растровую подготовку. В обоих порядках сравнивается старый и новый renderer в одном capture; prepared/fallback counters проверяют фактический путь. В номинацию не попадёт запуск с незаметным fallback на DOM. Финальная native-трасса остаётся вне сравнений.
