# Сокращённые эффекты Classic — 0.61, 10.11.2026

Владелец разрешил сократить сами эффекты после отрицательных архитектурных прототипов. В обычном Classic сокращённый вариант включён автоматически. Это изменение подачи, с реальной потерей части декора; прежняя плотность праздника больше не является условием оптимизации. Настройки телефона и новый диагностический прогон пользователя не нужны.

## Изменение

| До | В 0.61 |
|---|---|
| Фрагменты/лучи/волны поля до 1.25–1.5 с, затем энергетический контур | Локальное исчезновение очищенных плиток до 240 мс; без хвоста частиц и контура |
| Fullscreen Festival: осколки, раскрытие новой темы, дополнительный салют рекорда | В обычном Classic не запускается |
| Shake canvas и большое внешнее свечение очистки | Убраны |
| Отдельные награды за линии, пустое поле и рекорд; буквы/эмблема/перелёт к HUD | Одна плашка на ход на 900 мс: полная прибавка, главное событие, множитель и отметка рекорда |
| Отложенное поступление очков и набор счёта до 900 мс | Канонический счёт/рекорд видны сразу после сохранённого хода |
| Переход цветов UI/фона 1–1.8 с, ambient animation | Новая палитра сразу, без ambient loop; смена материала фигур 160 мс |
| Выступление награды продолжается поверх следующих ходов | Следующий сохранённый ход убирает прежнюю плашку; максимум одна |

Звук, вибрация, материалы фигур, сохранённое открытие темы, подсказка и взаимодействие остаются. Обычная установка получает короткий локальный отклик без отдельного всплывающего числа; очки видны в HUD. «Спокойные эффекты» сохраняются и сокращают движение ещё сильнее. Пауза/фон отменяют косметику, сохранённые очки не зависят от анимаций. Закрытие серии без бонуса тоже имеет одну короткую подпись.

Filter-glow 0.60 не переносится как принятый default: helper использует его только при явном диагностическом `filter`; в обычном сокращённом ходе glow не вызывается, постоянный will-change для filter снят.

Старый renderer сохранён для воспроизводимости прежних диагностических протоколов. Preview `clearTrace` явно сообщает, что измеряет прежние эффекты; его proof содержит `effectProfile: legacy`. Разработческий `effectsStudy=legacy` включает прежнюю подачу для контроля; `clearTrace=full&effectsStudy=compact` проверяет новую. Пользовательского переключателя новых профилей нет. Это не перестановка renderer и не новый GL-контекст.

## Полный цикл на стенде

Chromium 141, Linux SwiftShader, 392×872, DPR2.75. Квадрат поля 1024×1024 в обоих вариантах; частота Phaser и разрешение не снижались. В каждом независимом context два прогрева и два untraced эпизода по 8 секунд; порядок legacy/compact/compact/legacy. Итого 16 полных эпизодов (8 прогревов,8 сравнений). Трасс в этот прогон не добавляли. Оба пути используют legacy score-glow как контроль отклонённого filter0.60.

| Вариант | >33.4 мс, прямой | >33.4 мс, обратный | Средний RAF, мс | Max, мс |
|---|---|---|---:|---:|
| Прежние эффекты | 1 / 1 | 2 / 3 | 17.364 | 50.1 |
| Сокращённые | 1 / 1 | 0 / 0 | 16.718 | 83.3 |

Средний интервал снизился в обоих порядках; среднее четырёх эпизодов −3.7%, длинных интервалов суммарно7→2. Но отдельный max ухудшился: это не доказательство устранения всех рывков. RAF не является измерением показанных экраном кадров или GPU execution time; переносить проценты на физический POCO нельзя.

Во всех 16 эпизодах сохранены score=shownScore=1574, pending=0, пустое поле и тема5, нет JS ошибок и незавершённых наград. Новая подача подтверждена фактическими counters: 1 DOM-награда вместо3, Festival0 вместо148 созданных частиц, ambient0 кадров, VFX sprite peak0. Например, первый untraced sample: board draws146→12, inkPeak47→16; это ресурсные счётчики одного эпизода, не обещание процентного FPS.

Все семь метрик каждого из16 эпизодов независимо пересчитаны из сырых RAF-интервалов самим runner (112 точных совпадений). Порог >33.4 мс округляется до0.1мс по прежнему протоколу. Полные исходные интервалы сохранены отдельно; [компактные данные и fingerprints](compact-effects/benchmark.json).

Точный измеренный input сохранён commit `c48ca56ac98d776d9676166dff0c7882dcd2ce9d`. Финальная сборка устраняет неиспользуемый параметр награды и ограничивает подпись множителя для старых сохранений без scoringVersion; измеренный fixture festival-v4 исполняет прежний путь. Финальная регрессия проверяется на итоговом коде, аппаратная приёмка не заявляется.
