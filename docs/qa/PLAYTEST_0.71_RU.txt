Blocky 0.71 — ручное сравнение выдачи

Установи APK поверх прежнего Blocky, удалять игру не нужно. Если телефон не открывает APK, скачай ZIP, распакуй и открой APK из приложения «Файлы». Версия в настройках: 0.71.0-preview. Реклама тестовая, AppMetrica выключена.

1. Сначала можно продолжить прежнюю партию: её правила сохранены.
2. Для новой пробы: шестерёнка → «Новая партия» → «Экспериментальная выдача» → «Задачи и старты · v2» → «Новая партия».
3. Включи встроенную запись: шестерёнка → «Ещё настройки» → «Запись партии для разбора» → «Начать запись» → «Продолжить».
4. Играй как обычно. Подсказки и тестовое продолжение после поражения использовать можно. Для сравнения достаточно 1–2 партий; если партия затягивается, можно остановиться и сказать об этом.
5. До закрытия игры: шестерёнка → «Ещё настройки» → «Запись партии для разбора» → «Выгрузить запись партии». Пришли JSON. Видео необязательно.
6. Для прежнего варианта в следующей новой партии выбери «Задачи и старты · 0.70». Сначала выгрузи предыдущую запись и сохрани JSON, затем нажми «Удалить запись». После выбора следующей партии включи новую запись по шагу 3.

Коротко по ощущениям: были ли понятные задачи на несколько ходов; оставался ли выбор; сколько готовых полных очисток; можно ли проиграть; не затягивалась ли партия. Если дёргается — после какого действия и сразу ли после запуска или ближе к концу.

Новая версия исправляет побочные замены выдачи при неудачном поиске задачи. Она пока не прошла весь критерий баланса и не включена основной. Улучшение интересности и плавности телефона ещё предстоит проверить.
