# Supplementary composition control — frozen before its own collection

The primary D78 cohort has completed. Its source/protocol/data are unchanged.
Observed output distributions differ markedly (e.g. large-shape share), even
with the same catalogue support. Therefore primary comparisons alone cannot
separate the value of board conditioning from the value of the shape mixture.

Additional question: does assigning a generator's exact existing trays to
different boards degrade the measured opportunities? Use the existing48 snapshot
inputs in their saved order, independently per catalogue and policy. Circular
shifts1,17,31 assign each tray to a different board. Each shift preserves the
*exact multiset of three-piece bags*, joint composition and slot order. No
resampling, optimized assignment, fallback or new gameplay policy.

For each reassignment, independently search for complete placement at a24000
public fit/place budget, retaining found/impossible/unknown. Play clear/space/
three/bounded with the same first three roll streams already used for that
destination board. Compare with the saved own-tray plays. Report all assignments
and the explicitly selected both-proved subset separately; filtering changes the
conditional mixture and must not be advertised as an unchanged distribution.

This is a post-primary, fixed-input mechanistic control, not new holdout evidence
for a game-code candidate. Moving bags deliberately can create unsolvable trays;
they are diagnostic outcomes, not a proposed generator. Source-policy bias and
within-snapshot dependence remain. No human, retention or global-director claim.
