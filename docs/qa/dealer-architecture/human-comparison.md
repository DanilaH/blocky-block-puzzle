# Короткое сравнение существующих выдач — наблюдения ещё не собраны

Сборка0.63, одна и та же настройка эффектов/звука. В окне новой партии открыть
«Экспериментальная выдача»: A — «Прежняя выдача» (flow-v4), B — «С задачами и
нагрузкой» (director-v2). Новая партия обязательна: resume сохраняет старую
политику. Не менять настройки посреди сравнения. Не сравнивать старую почти
проигранную партию с новой пустой доской.

Первый качественный проход:3–5 человек, включая незнакомого с игрой и уверенного
игрока. Одному дать порядок A→B, следующему B→A. По8 минут на вариант либо до
добровольного выхода; продолжать до поражения не обязательно. Начать следующее
плечо новой партией. Не объяснять стратегию до наблюдения. Числа ниже — рамки
малого качественного теста, не расчёт мощности и не тест retention.

Зафиксировать версию/политику, знакомство с блоками, порядок, ход/скрин/запись
первой интересной возможности, первое непонятное последствие, каждую замеченную
полную очистку и добровольное прекращение. Запись партии — только по желанию.
Не просить одновременно думать вслух каждую секунду; достаточно короткого
объяснения после характерного решения.

| Наблюдение | Вариант A | Вариант B |
|---|---|---|
| Каким был понятный следующий хороший ход? | | |
| Увидел ли награду до размещения? Какую? | | |
| Где проверял порядок фигур? | | |
| Какие потери места/наград понял после действия? | | |
| Был ли отрезок однообразных постановок? Пример/ход | | |
| Праздник ощущался заработанным или автоматическим? | | |
| Почему остановился / почему проиграл? | | |
| Захотел ли сам начать ещё одну партию? | | |

После обоих вариантов выбрать предпочтительный и назвать конкретный момент,
который повлиял на выбор. Не подсказывать, что один вариант «умный» или «честный».
Записать и противоречащие гипотезе наблюдения. Один опытный владелец полезен как
отдельный case, но не заменяет нового игрока. Отсутствие наблюдений не заполнять
оценками ботов. Итог должен назвать одну повторяемую проблему для одного
минимального изменения либо оставить игру без нового вмешательства.
