# Preview 0.57 — разделение наград и цветов интерфейса

**Физический результат получен:** 18/18 valid, ни одно из четырёх узких условий не прошло порог в обоих порядках. Большие no-reward-dom/no-theme снова помогают; исправление рывков остаётся открытым. [Результат и границы вывода](PHONE_LAYER_FINDINGS_0.57_2026-11-08.md).

## Изменение

Растровый текст 0.56 не прошёл физическую приёмку. Удалены `RewardLabels`, кеш символов/Canvas, idle prewarm и связанная интеграция. Обычные награды снова используют прежние DOM-буквы; расчёт, атомарное сохранение, поступление очков 700/580 мс, перелёт, добор счёта и очистка по gameId не меняются. Локальные переходы Classic из 0.56 сохранены. Стабильная плавность этим откатом не объявляется.

В Classic эмблемы уже скрыты `arcade.css` (`display:none`), поэтому они не объявлены причиной задержки. Проверка подписи сохраняет прежнюю геометрию награды и суммы, скрывая подпись и выключая её анимации. Счётчик подтверждает ноль видимых эмблем во всех условиях.

## Один прогон

Пауза → Ещё настройки → Диагностика → Проверить слои. 18 эпизодов, около 80 секунд плюс сохранение трассы; schema `blocky-phone-layers-v3`. Warmup, два обратных прохода с контролем до/после, отдельный native baseline. Основные сравнения без native tracing. Сохранение партии, screen-awake, cancel/retry/captureId и один ZIP результата сохраняются.

| Условие | Меняется | Сохраняется |
|---|---|---|
| baseline | Полная обычная DOM-отрисовка | Все эффекты |
| no-hud-flashes | Пропуск двух анимаций счёта: text-shadow и масштаба | Числовой добор, перелёт, подпись, плашка темы, оформление |
| no-reward-decoration | Подпись скрыта с сохранением размеров; её transform/CSS-танец отключены | Сумма, перелёт, вспышки, плашки, оформление |
| no-dom-palette | Только CSS world-bg/ink/accent удерживаются на теме 1 | Новая тема 5 поля, материалов, Canvas фона/частиц и фоновых слоёв, плашка, импульс |
| no-theme-notice | Пропуск только плашки новой темы | Смена всех палитр, её прежний импульс фона, остальные награды |
| no-reward-dom | Прежнее большое отключение наград | Логическое поступление очков, числовой добор, фон/частицы/оформление |
| no-theme | Прежняя заморозка всего видимого оформления | Сохранённый wardrobe переходит в 5; плашка/импульс смены отсутствуют |

Обычный режим не читает эти диагностические флаги из URL. Отдельная база диагностического режима не меняет игровую партию. Условие без CSS-палитры не передаёт тему 1 в BoardScene/Festival/фоновую анимацию и не замораживает материал фигур. Условие без плашки оставляет `atmosphere.impulse(1.5)` на прежнем месте.

## Проверка фактических путей

В proof входят DOM renderer, количество запущенных анимаций подписи, видимых эмблем, перелётов и пар анимаций вспышки, созданных плашек и импульсов темы. Отдельно читаются фактически выставленные CSS world-цвета и целевые темы BoardScene/Atmosphere/Festival. Validator отклоняет пропавший перелёт, заморозку лишних палитр, оставшуюся вспышку или исчезнувший импульс в чужом варианте. Он проверяет 148 созданных частиц и прежний логический результат.

Порог номинации остался прежним: минимум вдвое меньше интервалов >33.4 мс в обоих порядках, без ухудшения максимума относительно соседних контролей с допуском 1 мс; локальный drift ограничен. Это номинация для исправления, не автоматическое доказательство причины. Fast DEV прогон не может номинировать результат; он удлинён до 1500 мс, чтобы проверить оба поступления очков и отложенный Festival burst.
