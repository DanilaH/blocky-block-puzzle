# D87: фиксированный протокол до кандидата

Основа D86/46c2751. Сначала guard revive и измерения. Один кандидат
`composition-v1` поверх frozen director-v2, отдельная версия и новая партия.
Default остаётся director-v2. Revive исправлен одинаково у обоих.

Кандидат: получить исходный v2 план. Если тройка уже содержит L3/T4/SZ4,
сохранить её. Иначе перебирать однослотовые замены только площадью 3/4,
сохраняя цвета и два других shapeId. Общий дополнительный бюджет 12000
операций на все альтернативы. Порядок семейств — меньше встреч в последних
четырёх лотках, затем фиксированный порядок L3/T4/SZ4 и ориентаций каталога.
Для payoff/relief/recovery сохранять найденный исходным witness all-clear
и минимум числа линий. Для остальных ролей — совместное решение и минимум
числа линий исходного witness. Кандидаты ранжируются по этому ограниченному
пулу; один первый доказанный подходящий выбирается, иначе точный baseline
с причиной no-slot/already-diverse/budget/no-role-proof. Семейная история
ограничена четырьмя тройками. RNG v2 не переопределять, дополнительный выбор
детерминирован и не требует рекламы/часов. Полный witness обновить вместе с
лотком. Сохранение площади не считать сохранением сложности.

они не являются независимой проверкой качества. Новая когорта: seed 4101001–
4101008, две политики, bounded/three/lapse из существующего стенда, до 180
ходов; отдельно ended/censored. Не тюнить пороги после результата. Критерии:
все witness/детерминизм/save PASS; больше малых непрямоугольных фигур среди
подходящих слотов; не хуже 20% по обычным clear-move rate в каждой модели;
не более +25% среднего ограниченного числа ходов; сохраняются поражения
lapse. Награды и повторения показать по ролям, не прятать за общим процентом.
Технический PASS не означает default/баланс ADOPT. Если gate FAIL — оставить
кандидата только экспериментальным и не создавать следующий.
