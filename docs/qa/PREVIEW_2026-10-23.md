# Preview QA — 23.10.2026

Объём: первый рабочий макет и основа Classic. Это не релизная приёмка M1/M5.

## Выполнено локально
- npm test: 15 проверок (2 файла): каталог/веса, пересечение линий, полная очистка/очки, RNG-векторы, детерминированный replay, недопустимый/повторный ход, точный конец, доказательство тройки и исчерпание бюджета, подсказка/кредит после reload, отказ записи, конфликт действий, независимые lifecycle blockers.
- npm run build: TypeScript и production Vite bundle проходят. Phaser chunk ~1.37 MB до gzip (~357 KB gzip); это предупреждение размера, не измеренный cold-start на телефоне.
- npm run test:e2e: 4 сценария Chromium: перенос/отмена, подсказка и reload без второго списания, пауза, поворот во время жеста, резервная копия, макет.
- Размеры: 320×568, 360×640, 390×844, 640×360, 844×390, 1024×768. Проверены границы поля/кнопки подсказки относительно нижнего резерва и горизонтальное переполнение.
- Скриншоты preview-portrait.png / preview-landscape.png просмотрены визуально. Поле для демонстрации получено 11 допустимыми ходами ядра на seed 1234 через тестовый fixture. Это экран настоящего рендера, не маркетинговый снимок органической сессии.
- Capacitor add/sync проходит; собственный debug package com.danilah.blocky.dev. CI подготовлен для JDK 21 и Android SDK 36.

## Найдено и исправлено в этом проходе
- Подписка на scene.events до завершения boot Phaser приводила к ошибке запуска. Убрана; scene.create рисует уже переданное состояние.
- Оценка корня поиска могла заменить допустимый fallback пустым путём перед таймаутом. Корень не участвует в выборе хода; добавлена проверка на 50 seed с малым бюджетом.
- Перенос захватывает pointer на стабильном контейнере лотка, чтобы не зависеть от заменяемой кнопки.

## Не проверено / ещё не реализовано
- APK на физическом телефоне, Android process death, обновление приложения, native safe insets и реальный палец.
- Реальные p95 запуска, подсказки, touch-to-preview, fps и длительная память. Headless Chromium не заменяет слабый Android.
- Нативная реклама, reward/revive, audio focus, AppMetrica. Нижняя область только резервируется. Прототип не симулирует заработанную рекламную награду.
- Финальный набор SFX, музыка, вибрация, вторая тема, интерактивное обучение; текущие звуки — первоначальный синтез.
- Сравнение на 1000 seed/комбинацию и 5 человеческих плейтестеров.
- Согласование оформления владельцем. M0/M1 остаются открытыми.

Локальная среда: Node 24.19.0, Chromium 141 (Playwright 1.56.1), Linux/headless. Локально установлен JDK 17, Android SDK отсутствует; сборка APK передана в workflow, её результат следует фиксировать отдельно после завершения run.
