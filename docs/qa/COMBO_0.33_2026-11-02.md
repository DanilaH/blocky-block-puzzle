# Комбо и музыка — preview 0.33

## Изменения

Новые партии используют `festival-v4`. Старые сохранения продолжают считать очки по своей версии; новый рекорд хранится в `progressionBest`, старые значения не удаляются. Выдача, RNG, условия очистки и два подготовительных хода прежние.

| Серия | Множитель линий | Оформление | Музыкальное развитие |
|---:|---:|---|---|
| 0–1 | ×1 | Пластик | Основной трек |
| 2 | ×1,5 | Янтарь | Шейкер |
| 3 | ×2 | Янтарь | Шейкер |
| 4 | ×3 | Вишнёвая эмаль | Добавляется деревянная перкуссия |
| 5 | ×4 | Вишнёвая эмаль | Два слоя |
| 6–7 | ×5 | Золото | Добавляется ручной барабан |
| 8–9 | ×6 | Лёд | Три слоя |
| 10–12 | ×8 | Хром | Барабан становится выразительнее |
| 13–15 | ×10 | Магма | Три слоя, ограниченная громкость |
| 16–19 | ×12 | Опал | Три слоя |
| 20–25 | ×15 на 20, ×16 на 23 | Затмение | Три слоя |
| 26–33 | ×17 на 26, далее +1 каждые 3 очистки | Нова | Три слоя |
| 34+ | Продолжается +1 каждые 3 очистки | Призма, оттенки далее каждые 8 | Три слоя |

Награда за пустое поле остаётся отдельной: +1000. Размер надписи растёт внутри ступени и между ступенями, ограничен 38 px и шириной поля. Хвост обычной награды растёт с 1650 до 2300 мс. Цвет/свет и входной отскок меняются по ступеням; пустое поле сохраняет приоритет, максимум 42 px. Одновременно остаётся не больше трёх наград. Спокойный режим сохраняет короткие сдержанные анимации.

## Звук

Коэффициент музыкальной шины 0,8 → 0,32: −7,96 dB при той же сохранённой настройке. Эффекты не ослаблены. Это применяется и к уже установленной игре без сброса настроек.

Три собственных синтезированных перкуссионных петли по 16 долей при 118 BPM дополняют выбранный D. Это не стемы оригинального трека. Они готовятся один раз после декодирования, а не при ходе; четыре фиксированных BufferSource вместе с основным треком. На смене серии меняется только gain. Дополнительные mono-буферы занимают около 2,24 MiB при 24 kHz. Подготовительные ходы сохраняют слои, потеря серии плавно их убирает. Пауза/реклама/потеря фокуса останавливают все источники, возобновление сохраняет общую фазу.

Слуховая оценка музыкальности и баланса на телефоне остаётся открытой. Техническая запись не заменяет прослушивание владельцем.

## Баланс

Детерминированные прогоны `initial-v1`, максимум 180 ходов на партию: random, greedy и beam ширины 3. Сводка и исходные данные в [combo-0.33](combo-0.33/summary.json). Это модели поведения, не статистика людей. Beam часто доходит до ограничения ходов, поэтому максимумы его серий — нижняя оценка для полной партии.

У greedy медиана максимальной серии 6; серия 8 встречается в 27 из 100 партий, 10 — в 15, 16 — в 3. Поэтому основные изменения перенесены в диапазон 2–16. Поздние оформления остаются редкими достижениями. Не пытаемся сделать серию 100 обязательной целью.

200 парных партий greedy с теми же ходами: средний счёт 4401,375 → 4724,375 (+7,34%), максимальное отношение нового счёта к старому 1,443. Поле, лоток и RNG совпадают после каждого хода; все 200 партий закончились до лимита 150 ходов. Изменён только подсчёт наград. Команды воспроизведения:

```
BALANCE_PLAYER=random BALANCE_OUTPUT_DIR=docs/qa/combo-0.33 node scripts/compare-dealers.mjs initial-v1 100 180
BALANCE_PLAYER=greedy BALANCE_OUTPUT_DIR=docs/qa/combo-0.33 node scripts/compare-dealers.mjs initial-v1 100 180
BALANCE_PLAYER=beam3 BALANCE_OUTPUT_DIR=docs/qa/combo-0.33 node scripts/compare-dealers.mjs initial-v1 100 180
node scripts/compare-progression.mjs
```

## Производительность

`TileMaterialDOM.set` больше не сканирует документ, если материал не менялся. Новые кнопки лотка синхронизируются локально. Убрана анимация box-shadow рамки поля; плавная смена цвета и материалов сохранена. Новые музыкальные источники не создаются при очистке/смене темы. Фон переведён на существующий opacity-crossfade двух фиксированных поверхностей: раньше эти div не имели размеров, а цвет анимировался на root/body. Убраны две полноэкранные цветовые анимации.

Одиночные программные Chromium-замеры не доказывают улучшение FPS: full-combo p95 был 33,5 мс, стал 49,9 мс, медиана осталась 16,7 мс. Отключение DOM crossfade также не улучшило исходный результат. Эти измерения шумные, сделаны не на Android; нельзя объявлять пользовательскую просадку устранённой. Raw: performance-before.json, performance-after.json. Изолированный переход без очисток тоже воспроизводит задержку: JS render 3–5 мс, p95 кадров 33–67 мс. Проба с фиксированными фоновыми поверхностями сократила максимум long task со 129 до 66 мс в одном прогоне, но не улучшила p95 стабильно. Нужен аппаратный trace смены темы и длинной серии; этот gate открыт.

Изолированный сценарий воспроизводится через `node scripts/probe-theme-performance.mjs`; результат по умолчанию `/tmp/blocky-theme-only.json`.
