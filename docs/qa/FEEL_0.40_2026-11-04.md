- Простое увеличение backing с MSAA ухудшило медиану all-clear с 16,7 до 33,3 мс; такой вариант отклонён.

- Idle-drag p95: исходный 16,8/33,3 мс; новый 16,8/16,8 мс. Никакого физического Android FPS здесь нет.
- Сырые результаты: `base40-final.json`, `feel40-final.json` (отклонённый MSAA), `feel40-nomsaa.json`.

## Подпись кандидата
Push CI `41809939998` прошёл 142 unit, 122 browser, Android unit/build. Однако его APK artifact `13312880622` подписан сертификатом `6aabd8759b76860bfa4b266de4af0b4bf2e1cbc31ada518198ea740d0066066a`, который отличается от установленного preview 0.39 (`e96d…be13`). Этот кандидат отклонён для обновления и пользователю не выдан. Вероятная причина — раздельные scope кеша preview keystore у push и pull_request; push лог подтверждает восстановление существующего кеша с тем же именем. Для доставки проверяется именно PR APK; удалять существующую игру ради несовместимой подписи не требуется.
