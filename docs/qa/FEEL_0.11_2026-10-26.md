# Preview 0.11 — глянцевые фишки и исправления полного аудита

Дата: 26.10.2026. Игровой commit: `cfd065c5ca7bd450fdb258c522c91dc816278849`.

## Что изменено

Единая геометрия фишки для SVG-лотка, переносимой фигуры и Phaser-поля: скруглённый силуэт, толстая нижняя грань, широкое отражение и тонкий блик. Цвета различимы по прежней игровой логике; собственная графика построена кодом, новых внешних изображений/шрифтов/звуковых файлов нет. SVG по цвету кешируется.

Поле получило тёмную углублённую основу, фон — спокойное освещение. Золотистый акцент объединяет основные кнопки, награды и результат. Пауза, переключатели, подсказка, ошибки старта и результат используют ту же палитру и материал. Результат показывает количество ходов и факт использования подсказки. Сохранены отдельные по силе награды обычного хода, линии, комбо и пустого поля; свет волны и рамка all-clear согласованы с новым материалом. Общий контакт 0.10 сохранён; высокочастотная часть укорочена с 18 до 12 мс и немного приглушена. Предел шести голосов сохранён.

Это реализация согласованного направления, а не утверждение, что визуал и звук уже приняты владельцем на телефоне.

## Закрытые находки аудита

| Находка 0.10 | Новое поведение |
|---|---|
| Пауза пишет «сохранена» во время записи | Показывает «Сохраняем…», затем подтверждённое состояние; при отказе выводит ошибку |
| Рестарт при занятой записи молча игнорируется | Зависимые действия и настройки временно отключены; паузу можно закрыть |
| Подсказка убирает busy до записи | Индикатор проходит весь цикл расчёт → сохранение → показ; списание и контур публикуются после записи |
| Две повреждённые копии дают бесконечный retry | Отдельное объяснение, повтор загрузки и подтверждаемое начало заново |
| Опасность потери исходных повреждённых данных | Архив обеих записей и новый профиль создаются одной транзакцией; при сбое всё откатывается |
| Другой экран успел восстановить профиль | Recovery повторно проверяет обе записи внутри транзакции и не заменяет валидный профиль |
| Конфликт двух страниц предлагает бесполезный повтор | Загружается подтверждённое сохранение, объясняется конфликт; следующий ход доступен |
| Поле 152×152 на 320×480 | Поле 256×256; подсказка рядом с лотком, кнопка остаётся 48 px; обучение сохраняет отдельную строку |

Архив повреждённых записей находится в том же локальном IndexedDB, отдельно от `current`/`backup`. Это диагностическое сохранение исходных данных, не облачная копия и не обещание автоматического восстановления рекорда. При временной недоступности хранилища разрушительный reset не предлагается. Никакие пользовательские данные во время разработки не сбрасывались: сценарии выполнялись в изолированных тестовых профилях.

## Проверки

До последней защитной правки recovery полный локальный прогон: 27 unit + 41 e2e, TypeScript/production build прошли. После правки повторно прошли все 10 новых recovery/layout e2e и production build. Финальный полный CI-прогон указан ниже.

Новые сценарии `e2e/recovery.spec.ts`: success/failure записи хода с открытой паузой; success/failure сохранения подсказки; подтверждение/отмена восстановления; атомарное сохранение архива; отказ записи после постановки архива в транзакцию с проверкой полного rollback; защита уже восстановленной партии; валидный backup; временная ошибка открытия без reset; конфликт двух страниц с последующим допустимым ходом; геометрия короткого портрета.

Существующая матрица проверяет safe-area, обучение, оба порядка отпускания при мультитаче, потерю/восстановление WebGL, фон, быстрые ходы во время частиц, сохранение наград и спокойную интенсивность.

Дополнительно `scripts/stress-gloss.mjs`: 100 ходов через реальный UI, 3 перезапуска завершённых партий. После завершения эффектов: 0 impacts, 0 voices, 0 DOM-анимаций; максимум 2/6. За 1.2 с на паузе — 0 postrender; при подсказке — 72 draw с суммарным временем около 8.7 мс на текущем Chromium. Это ограниченная проверка ресурсов и JS-времени, не аппаратный FPS, GPU-профиль или 30-минутный тест. При задержанном сохранении подсказки зафиксированы `aria-busy=true` и видимая подпись «Сохраняем…». [Данные](feel-0.11/runtime.json).

## Границы

Правила, выдача, очки, лимиты подсказок и интерактивное обучение не менялись. Native-реклама, reward/revive, аналитика, музыка, haptics, вторая тема и audio focus остаются отдельной платформенной работой по ТЗ. Динамик/наушники, физическая точность жеста, установка обновления, 20–30 минут на телефоне и человеческая оценка оформления в этом окружении не проверены.
