## Поведение

- Обычный первый запуск после обучения, новая партия из паузы, повтор после результата и восстановление повреждённого профиля используют выбранный v2.
- Уже сохранённая партия, её policy/seed/board/tray, готовые эффекты revive, заработанные подсказки и recovery продолжаются по прежним правилам. Никакой миграции баланса внутри партии.
- В диалоге новой партии по умолчанию выбран «Задачи и старты · v2 (основная)». Исторические варианты доступны в свёрнутом разделе «Другие варианты выдачи». Старый выбор для сравнения не подменяет обычный запуск; при желании его можно выбрать явно для следующей партии.
- Партия, история стартов и ручной выбор сохраняются одной транзакцией и при рестарте из паузы, и после поражения. Убрана отдельная запись manualDealer после уже сохранённой новой партии. При сбое сохранения остаются прежние игра/история/права, повтор сохраняет одну новую партию.
- Первая история старта записывается с первым новым профилем; простая загрузка старой партии её не дописывает.
- A/B-конфигурации OFF, устойчивые существующие assignment IDs не пересоздаются; ручная проба и обычный режим различаются comparisonMode. Текущий запуск всех новых партий на выбранном v2 — решение владельца о поставке, не скрытый случайный rollout.
- Алгоритмы выдачи, каталог, RNG, фазовые параметры, revive/лимиты/права, реклама и эффекты не менялись. Версия0.72/code72, package и схема сохранения прежние, demo ads / analytics OFF.
