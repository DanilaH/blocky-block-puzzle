# Оптимизация 0.26

## Изменения

- WebGL: Graphics для контуров поля, теней, бликов, превью и колец заменён одним подготовленным атласом 960×800 (3.07 MB RGBA). Обычные Image объединяются в спрайтовый проход; большие рамки используют восемь частей без растяжения углов. Пул контуров прогревается при запуске и ограничен. Статические обводки/контактные тени объединены в одну текстуру 512×512 (1 MB RGBA), обновляемую только при изменении заполнения поля, а не на каждом кадре темы. Цена кэша — около 4.1 MB RGBA texels, плюс служебные структуры и возможные отдельные CPU/GPU-копии; не считать это полным расходом памяти. Canvas fallback сохраняет Graphics. NineSlice-прототип исключён после предварительного замера.
- Drag: геометрия на захват, translate вместо left/top при движении, последний sample за RAF, превью при смене клетки. Pointerup использует собственную координату независимо от очереди RAF. Отмена очищает очередь. Захват больше не вызывает полный render интерфейса.
- Поиск похвалы приостанавливается во время жеста; готовый результат того же revision сохраняется.
- Phaser явно ограничен 60 Гц; Festival и Atmosphere используют общий косметический clock (60/30 Гц). Звук остаётся на WebAudio clock.
- Основная очистка и all-clear сохранены. Дополнительный боковой салют серии ≥6: 64 вместо 200; вместе с обычным burst пик 194 вместо 330. Festival ограничен 260; мёртвые частицы удаляются без нового массива каждый кадр.
- Цвет фона: compositor crossfade двух слоёв; оттенки небольших эмалевых элементов интерполируются локально. Корневые наследуемые свойства больше не анимируются. Последний кадр перехода Phaser гарантирован даже после длинного кадра.
- Награды сдвигаются translate вместо анимации margin; убраны map/reverse/spread внутри цикла клеток.
- Баннер: JS дедуплицирует неизменившуюся геометрию, native epoch инвалидирует кэш; Java не вызывает setLayoutParams для того же прямоугольника.
- Опциональная диагностика в паузе: до 7200 RAF-интервалов и 512 фаз; паузы исключены. Замер applyMove отдельно от wall time сохранения, стоимость boardDraw. JSON не содержит сохранение/идентификаторы игрока. Android экспортирует через FileProvider/system chooser; web скачивает JSON.
