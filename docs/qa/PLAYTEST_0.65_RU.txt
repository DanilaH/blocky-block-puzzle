Blocky0.65 — короткая проба

1. Установить APK поверх0.64, приложение не удалять.
2. Пауза → Начать заново → Экспериментальная выдача.
3. Выбрать «Разный старт и темп · новая проба» → Новая партия.
4. Сыграть2–3 начала: разные ли фигуры/ситуации, не стало ли слишком тяжело
   сразу. Для начала хватит по15–25 ходов; новую партию запускать через паузу.
5. Если интересно — одну партию подольше. После72 ходов меняется помощь.
   Бесконечно доигрывать не надо: если затянулось/скучно, остановиться и так
   и написать. Сокращение хвоста пока не подтверждено устойчиво ботами.
6. Для сравнения прежний кандидат — «Разнообразные формы · проба».
   «С задачами и нагрузкой» — старый v2, он тоже сохранён.

Запись: Пауза → Дополнительно → Запись партии для разбора → Начать запись
перед новой партией. После пробы там же выгрузить JSON. Видеозапись экрана
для баланса не нужна. Если воспроизводится лаг — отдельная короткая проверка
без видео, сохранить игровую запись и отметить примерно момент/число ходов.

Достаточно: какой режим, когда стало скучно/тесно, были ли интересные
решения на несколько шагов и хотелось ли начать снова. Для revive —
получилось ли продолжить после тестовой рекламы. AppMetrica выключена.
