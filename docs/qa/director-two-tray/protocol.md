# Two-tray construction and payoff — protocol before candidate outcomes

2026-11-10. Baseline game d791ce0904f563012e31df4c5f3bd766ed571ac8 / unchanged flow-v4. Research builds on b8d20cf2ed56fd1f0726792ee5adad779684878e. The owner approved continuing with a short task → resolution → reward sequence.

Hypothesis: the previous varied opening lost early all-clears because its continuation was not constructed. Generate a varied first tray only if an explicit six-move route through a second tray finishes the board. At the actual second refill validate the stored route against the actual board; if it differs, solve the payoff again from that board. Search exhaustion or no proven target falls back to the ordinary tray. No speculative future input is exposed to the independent players.

Scope: first two trays of a new game only, then unchanged flow-v4. Existing catalog, max6 cells for opening pieces, weights and scoring remain. No new figures, mastery model, recurring forced clears, timer, ads or hidden defeat. Candidate selection never queries evaluation bots. Future RNG remains the RNG computed by the ordinary game path on the actual current board. Director state is separate and serializable; ordinary saves/default/APK are not changed by this offline experiment.

Construction: at most4 weighted diverse opening proposals. First-tray witness must not already clear the board. Payoff searches exact covers of unions of at most4 complete rows/columns containing all currently occupied cells, using exactly3 existing figures. The solver replays all proposed placements through the rules, including intermediate clears, and requires a final empty board. The target class is incomplete; no failed search is called globally unsolvable. At most12000 placement checks per solve. A successful stored payoff is reused only after board and witness validation. Total initial solver budget≤48000, actual payoff recomputation≤12000. These are search bounds, not player difficulty/skill measurements.

Tests cover legal witnesses, deterministic replay, input immutability, changed actual boards, stale routes, serialization, spent-stage behavior and low/zero budgets.

Each trajectory must replay from recorded moves. Independently recompute all event metrics and gate decisions. Disclose duplicated strategy trajectories, censoring, fallback/repair coverage, actual versus witnessed payoff and first-line/full-clear timings. A witness is not a prediction of player action.

Gate: no illegal move, mutated input, changed ordinary future RNG, stale route application or exceeded search budget; at least6/8 seeds in each split receive a different initial tray, and at least8 distinct candidate opening family compositions across both splits. In each split/style require≥95% baseline lines/move,≥90% all-clears/move, at most one fewer game reaching180 and at most one additional ordinary-dealer fallback. First line by12 and all-clear by30 must each occur in at least baseline minus1/8 games per style/split. Among completed construction stages, at least75% must achieve the actual intended all-clear during the next tray. Cloud initial planning p95≤100ms and actual payoff p95≤60ms; no phone-FPS inference.

Do not tune on confirmation or silently relax a gate. Passing this bounded study permits a separately versioned human candidate; it does not prove global balance, retention or physical performance.
