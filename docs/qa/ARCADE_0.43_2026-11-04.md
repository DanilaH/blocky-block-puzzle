# Preview 0.43 — сдержанный аркадный UI

Утверждённый второй концепт перенесён в Classic: насыщенная синяя базовая тема, тонкая рамка тёмного поля, белые наклонные цифры, янтарный рекорд, зелёные основные действия. Пауза, помощь, подтверждения и библиотека тем используют единый navy UI. Ревайв сохраняет кольцо и одну кнопку на поле; результат — отдельный экран. Тема выбирается по мини-превью с реальными текстурами фигур. Большие эмблемы скрыты, эффекты очисток не изменены.

Новый слой `src/arcade.css` импортируется последним. Фон — статические CSS-градиенты без новых растровых текстур и без кадровой перерисовки JS. Превью переиспользуют существующие WebP, с lazy загрузкой. Размытие backdrop снято; игровая геометрия, расчёты, scoring, RNG и реклама не менялись.

Локальные проверки: build; 144 unit; 124 browser (полный прогон, 7.9 минуты; перед ним 22 целевых); assets:check. Портрет 320×480, 320×568, 390×844 и альбом 568×320 покрыты существующими layout-проверками. Контраст результата проверен автоматикой. Скриншоты в `arcade-0.43/`, запись воспроизводится `CAPTURE_DIR=/tmp/arcade43 node scripts/record-arcade43.mjs`.

Запись использует подготовленную проигрышную позицию и mock rewarded: это проверка интерфейса, не реального рекламного SDK. Все 11 превью проверены на загрузку реальных текстур и отсутствие переполнения карточек. Светлая тема проверена отдельно: затемняющий слой применяется только к синей базовой. Сохранение проверено при обновлении web payload 0.42 → 0.43 на одном origin; профиль совпал полностью. Это не тест нативной установки. Код: `42a5d4aadfd316596aa39f0655ad27fcae545b63`.
