# Preview 0.43 — сдержанный аркадный UI

Утверждённый второй концепт перенесён в Classic: насыщенная синяя базовая тема, тонкая рамка тёмного поля, белые наклонные цифры, янтарный рекорд, зелёные основные действия. Пауза, помощь, подтверждения и библиотека тем используют единый navy UI. Ревайв сохраняет кольцо и одну кнопку на поле; результат — отдельный экран. Тема выбирается по мини-превью с реальными текстурами фигур. Большие эмблемы скрыты, эффекты очисток не изменены.

Новый слой `src/arcade.css` импортируется последним. Фон — статические CSS-градиенты без новых растровых текстур и без кадровой перерисовки JS. Превью переиспользуют существующие WebP, с lazy загрузкой. Размытие backdrop снято; игровая геометрия, расчёты, scoring, RNG и реклама не менялись.

Локальные проверки: build; 144 unit; 22 browser (ads, readability, evolution, uiux-027); assets:check. Портрет 320×480, 320×568, 390×844 и альбом 568×320 покрыты существующими layout-проверками. Контраст результата проверен автоматикой. Скриншоты в `arcade-0.43/`, запись воспроизводится `CAPTURE_DIR=/tmp/arcade43 node scripts/record-arcade43.mjs`.

Запись использует подготовленную проигрышную позицию и mock rewarded: это проверка интерфейса, не реального рекламного SDK. Полный CI, Android и артефакт будут добавлены после получения результатов. Физическая плавность/звук/вибрация и оценка владельца остаются открытыми.
